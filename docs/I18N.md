# i18n — dois idiomas, sem reload

Atlas fala **pt-BR** (base) e **en**. A escolha do usuário vive no aparelho;
não existe rota `/pt-BR/...`, cookie nem servidor.

## Como funciona

| Peça | Onde |
|---|---|
| Mensagens | `messages/pt-BR.json`, `messages/en.json` |
| Locales e estratégia | `project.inlang/settings.json`, `project.inlang/paraglide.config.ts` |
| Resolução (pura, testada) | `src/lib/i18n/locale.ts` |
| Estado reativo e troca | `src/lib/i18n/locale.svelte.ts` (`i18n.locale`, `setLocaleChoice`) |
| `Intl` (data/moeda) | `src/lib/i18n/intl.ts` (`intlLocale()`) |
| Guard contra copy solta | `src/lib/i18n/hardcoded.test.ts` |

Regras de resolução, em ordem:
1. escolha salva (`atlas.locale.mode`) — `pt-BR`, `en` ou `system`;
2. idioma do sistema: `pt*` → pt-BR, **qualquer outra língua → en**;
3. `baseLocale` (pt-BR) é só fallback de chave ausente.

Trocar o idioma **não recarrega** a página: `+page.svelte` envolve o app num
`{#key i18n.locale}`. As funções `m.*()` do Paraglide não são reativas, então a
remontagem é o que faz a árvore inteira reler as mensagens.

## Escrevendo copy

- Toda string visível vem de `m.chave()`. Isso inclui `placeholder`,
  `aria-label`, `title`, `alt`, toasts, erros e estados vazios.
- Chaves em `snake_case`, prefixadas pela área: `settings_`, `fin_`, `notes_`,
  `graph_`, `trash_`, `common_`…
- Interpolação sempre na mensagem (`"synced {minutes} min ago"`), nunca por
  concatenação.
- Plurais: duas chaves (`*_one` / `*_many`) escolhidas por mensagem inteira.
- **Não** entram no catálogo: números, símbolos, unidades (`kg`, `min`), ids,
  classes CSS, nomes próprios ("Atlas"), datas e dados do usuário.
- Dados criados pelo app (categorias, domínios do grafo, rótulos sim/não) são
  semeados no idioma do primeiro boot e ficam gravados; trocar o idioma depois
  **não** renomeia dados existentes.

## Guard

`npm test` roda `hardcoded.test.ts`: qualquer nó de texto/atributo com copy em
arquivo fora de `hardcoded-allowlist.json` quebra o CI. Ao migrar uma tela, a
lista encolhe; para regravá-la use:

```sh
UPDATE_I18N_ALLOWLIST=1 npx vitest run src/lib/i18n/hardcoded.test.ts
```

Nunca use o comando acima para "consertar" uma tela nova — ele esconde o
problema em vez de traduzir.

## Limitações conhecidas

- Strings dentro de `<script>` e em módulos `.ts` ainda não são cobertas pelo
  guard (o detector cobre markup/atributos). Migração manual nesses casos.
- Também não entram no guard: rótulos que vêm de arrays de dados em `lib/`
  (tratados por funções como `horizonLabel`, `sourceLabel`).
